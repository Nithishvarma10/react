# React Router Learning Project 🚀

A React project built to learn and practice **React Router, navigation, nested routes, dynamic routes, `useParams()`, and API integration**.

## 🛠️ Tech Stack

- React.js
- React Router DOM
- JavaScript
- Tailwind CSS
- Vite
- Git & GitHub
- GitHub API

## ✨ Features

- 🏠 Home
- ℹ️ About
- 📞 Contact
- 👤 Dynamic User route
- 🔗 `NavLink` navigation
- 📦 Nested routing with `Outlet`
- 🔢 Dynamic routes using `useParams()`
- 🌐 GitHub API integration
- ⚡ `useState()` & `useEffect()`

## 🧭 Routes

```text
/                 → Home
/about            → About
/contact          → Contact
/user/:userid     → Dynamic User
